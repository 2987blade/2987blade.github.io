Who Am I

INTRO

I'm Kush — 2987blade. I break things to understand how they're built, then build better ones. My focus is offensive security: Active Directory attack paths, web application exploitation, and the tooling that makes engagements repeatable.

Most of my time goes into labs, source code, and terminals — chasing the "why" behind a vulnerability, not just the "how." When existing tools don't fit the problem, I build my own.

Long-term, I'm working toward senior offensive security roles with Active Directory red teaming as my core specialization — CRTP, CRTE, and OSCP are next.
